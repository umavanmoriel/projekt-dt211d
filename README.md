# Projekt
## Projektets syfte:
- Syftet med projektet är att använda tidigare kunskaper för att bygga en webbplats med en tydlig målgrupp och grafisk profil. 
- Webbplatsen ska skapas med hjälp av automatiserade arbetsprocesser och versionshantering med till exempel GitHub. 
- Majoritet av innehållet ska hämtas från externa källor.
- Webbplatsen ska använda minst två stycken olika webbtjänster/API:er, och dessa skall på något sätt kommunicera med varandra.
## Projektet bildades med hjälp av:
- Node.js och Parcell för automatisering och optimering
- Styling med SASS SCSS
- Versionshantering med GitHub
- Exerna källor: Apier
